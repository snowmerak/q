## 启动 Studio

Q Studio 是日常工作的主要界面。q 二进制文件直接提供内置的 Svelte 应用，无需安装单独的 Web 服务。

```powershell
q studio
```

Studio 在回环地址上监听并打开浏览器。使用 `--port <port>` 指定端口，或使用 `--no-open` 禁止自动打开浏览器。启动 Studio 的目录不会限制工作区。每个已注册的根会话都会单独记录代理运行所在的仓库目录。

## 会话与委派

在 **Sessions** 中选择仓库目录，然后注册已有根会话或创建新会话。来自不同仓库的根会话会显示在同一列表中。选择会话后，可以查看聊天、上下文用量、当前运行控制和委派的子会话。

消息以安全的 Markdown 呈现，并带有语法高亮。运行不依赖浏览器连接，刷新页面后 Studio 会重新连接事件流。代理提问、暂停或需要指导时，可在所选运行中回复，也可以暂停、恢复或停止正在执行的工作。

委派以树形显示。选择子节点可查看它自己的对话和嵌套工作。已完成的子节点可从聊天标题栏删除；删除会移除该节点及其所有后代，但保留父对话中已完成的工具交互记录。

## 审查仓库工作

**Changes** 显示整个仓库中已暂存、未暂存、重命名和未跟踪的文件。选择文件后，可以查看带行锚点、大小受限且高亮显示的 diff。

提交工作流会生成一个或多个 Conventional Commit 提案。你可以编辑消息、重新生成提案、选择要创建的提交，并选择是否推送。Studio 会在提交前检查当前索引是否仍与审查时一致。

## 设置与运维

**Settings** 管理全局模型与角色分配、Gateway 提供商、System One 提供商与决策模型、运行时限制、服务、职业型子代理、Agent Skills、MCP、语言服务器和 `.qignore`。字段更改后会自动保存，不需要单独的保存快捷键。

选择工作区后会显示仓库级模型覆盖。提供商变更无需重启 Studio，会从下一轮开始生效。API 密钥按 secret 处理，读取 API 不会返回密钥值。

**Operations** 显示令牌用量、活动与驻留运行、本地服务健康状态、保留数据和受限日志。**Help** 列出 Studio 快捷键，以及兼容命令当前打开的 Studio 页面。

## 本地运行时边界

Studio 绑定到回环地址，文件、进程、Git 和配置操作均由本地 q 进程执行。浏览器不会获得直接访问文件系统的权限。Shell 命令仍以本地 q 进程的权限运行，并非操作系统沙箱。

bare `q` 继续作为兼容聊天客户端，`q acp` 继续作为 ACP 服务器入口。`q model`、`q gateway`、`q systemone`、`q subagents`、`q skills`、`q mcp` 和 `q lsp` 等配置命令会打开对应的 Studio 页面。
