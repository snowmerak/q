## 什么是q

q 是面向终端、原生融入工作区的编码代理。在代码仓库或项目目录中启动它，即可通过一个 Go 二进制文件使用对话、文件工具、Shell 命令、模型提供商、规划、子代理、审查和持久历史。

工作区是 q 文件工具的操作边界。Shell 命令也从这里启动，但它们**不是操作系统沙箱**。请像审查本地开发 Shell 一样审查命令和审批。

## 选择工作流

如果请求范围明确，希望 q 直接检查或编辑，请使用普通对话。

普通聊天可以直接使用工作区工具，同时协调职业角色子代理。manager 作为 PM 负责规划，senior developer 可以直接实施，也可以分配并审查实施任务。

用 `/subagent` 将一个范围明确的请求交给专门代理。

## q会保留什么

每个工作区都可以保存多个持久会话。可见对话、压缩后的模型上下文、任务生命周期、委派状态和可搜索的工作区历史分别存储。长时间工作时，无需每轮都发送全部过去内容，也能检查过程。

q 还支持 Agent Skills。技能元数据按需搜索；只有代理加载适用技能后，完整的 `SKILL.md` 才会进入模型上下文。
