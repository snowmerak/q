## 什么是q

q 是工作区原生开发环境。本地 Studio 通过一个 Go 二进制文件提供对话、文件工具、Shell 命令、模型提供商、职业型子代理、仓库审查和持久历史。

工作区是 q 文件工具的操作边界。Shell 命令也从这里启动，但它们**不是操作系统沙箱**。请像审查本地开发 Shell 一样审查命令和审批。

## 选择工作流

在 Studio 中创建或注册仓库会话，让 q 在该工作区中检查、编辑或协调工作。

普通聊天可以直接使用工作区工具，同时协调职业角色子代理。manager 作为 PM 负责规划，senior developer 可以直接实施，也可以分配并审查实施任务。

需要专家处理范围明确的请求时，可让主代理进行委派。bare `q` 兼容聊天客户端仍可通过 `/subagent` 明确选择角色。

## q会保留什么

每个工作区都可以保存多个持久会话，Studio 会集中显示从不同仓库注册的根会话。可见对话、压缩后的模型上下文、任务生命周期、委派状态和可搜索的工作区历史分别存储。

q 还支持 Agent Skills。技能元数据按需搜索；只有代理加载适用技能后，完整的 `SKILL.md` 才会进入模型上下文。

## 下一步

通过 `go install` 或源码检出安装 q，运行 `q studio`，然后注册希望 q 理解的仓库。
