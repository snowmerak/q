## Delegate a task

Use `/mode delegation` in a workspace session, then describe the outcome you want. The main agent can ask the manager to turn requirements into a plan and ask the senior developer to guide implementation. `q sprint <request...>` runs one delegated task without the interactive UI.

## Roles

The manager is a PM role responsible for requirements, priorities, and acceptance criteria. The interviewer identifies decisions that require user input, and the researcher investigates focused questions. The senior developer uses the `reviewer` model role to assign bounded implementation to the junior developer, review actual changes and verification, and request corrections when needed. The junior developer uses the `coder` model role.

Each role may read relevant workspace evidence directly. The junior developer has the editing and command tools needed to implement assigned work.
