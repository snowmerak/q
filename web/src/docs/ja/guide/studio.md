## Studio を起動

Q Studio は日常作業の基本インターフェースです。q バイナリが組み込みの Svelte アプリを配信するため、別の Web サービスは必要ありません。

```powershell
q studio
```

Studio はループバックで待ち受け、ブラウザを開きます。`--port <port>` でポートを指定し、`--no-open` でブラウザの自動起動を止められます。Studio を起動したディレクトリがワークスペースを制限することはありません。登録した各ルートセッションが、エージェントを実行するリポジトリを保持します。

## セッションと委任

**Sessions** でリポジトリを選び、既存のルートセッションを登録するか新規作成します。異なるリポジトリのルートセッションを一つの一覧で扱えます。セッションを選ぶと、チャット、コンテキスト使用量、実行制御、委任した子が開きます。

メッセージはシンタックスハイライト付きの安全な Markdown として描画されます。実行はブラウザ接続と独立して継続し、更新後はイベントストリームへ再接続します。質問への回答、指示の追加、一時停止、再開、停止は選択中の実行に対して行います。

委任はツリーで表示されます。子を選ぶと、その会話と入れ子の作業を確認できます。完了した子はチャットヘッダーから削除できます。削除対象とその子孫はすべて消えますが、親の会話に記録された完了済みツール交換は残ります。

## リポジトリ作業のレビュー

**Changes** はステージ済み、未ステージ、名前変更、未追跡ファイルをリポジトリ全体から表示します。ファイルを選ぶと、行アンカー付きのサイズ制限されたハイライト diff を確認できます。

コミットワークフローは一つ以上の Conventional Commit 提案を作成します。メッセージの編集、再生成、作成するコミットの選択、任意の push が可能です。コミット前に、レビューした index と現在の index が一致するか確認されます。

## 設定と運用

**Settings** では、グローバルモデルとロール、Gateway、System One、ランタイム制限、サービス、職種型サブエージェント、Agent Skills、MCP、言語サーバー、`.qignore` を管理します。フィールドは変更時に自動保存され、保存ショートカットはありません。

ワークスペースを選ぶとリポジトリ固有のモデル設定も表示されます。プロバイダー変更は Studio の再起動なしで次のターンから適用されます。API キーは secret として扱われ、読み取り API から返されません。

**Operations** はトークン使用量、実行状態、ローカルサービスの状態、保持データ、制限されたログを表示します。**Help** は Studio のショートカットと互換コマンドの移動先を案内します。

## ローカルランタイム境界

Studio はループバックにバインドされ、ファイル、プロセス、Git、設定操作はローカルの q プロセスが実行します。ブラウザがファイルシステムへ直接アクセスすることはありません。シェルコマンドはローカル q プロセスの権限で動作し、OS サンドボックスではありません。

bare `q` は互換チャットクライアントとして、`q acp` は ACP サーバーとして残ります。`q model`、`q gateway`、`q systemone`、`q subagents`、`q skills`、`q mcp`、`q lsp` などは対応する Studio 画面を開きます。
