## qとは

q はワークスペースネイティブな開発環境です。ローカル Studio が会話、ファイルツール、シェルコマンド、モデルプロバイダー、職種型サブエージェント、リポジトリレビュー、永続履歴を一つの Go バイナリで提供します。

ワークスペースは q のファイルツールの動作境界です。シェルコマンドもそこで開始しますが、**OS のサンドボックスではありません**。ローカル開発シェルと同じ注意を払ってコマンドと承認を確認してください。

## ワークフローを選ぶ

q に調査、編集、作業調整を任せるリポジトリを Studio セッションとして作成または登録します。

通常のチャットはワークスペースツールを直接使いながら、職務別サブエージェントを調整できます。manager は PM として計画を担当し、senior developer は自分で実装するか実装を割り当ててレビューします。

限定された作業を専門家に任せる場合は、メインエージェントに委任を依頼します。互換クライアントの bare `q` では `/subagent` でロールを明示できます。

## qが保持するもの

各ワークスペースは複数の永続セッションを持ち、Studio は異なるリポジトリから登録したルートセッションをまとめて表示します。表示される会話、圧縮されたモデルコンテキスト、タスクライフサイクル、委任状態、検索可能なワークスペース履歴は別々に保存されます。

q は Agent Skills にも対応します。スキルのメタデータは必要なときに検索され、完全な `SKILL.md` はエージェントが適用可能なスキルを読み込んだ後にだけモデルコンテキストへ入ります。

## 次のステップ

`go install` またはソースチェックアウトから q をインストールし、`q studio` を実行して対象リポジトリを登録してください。
