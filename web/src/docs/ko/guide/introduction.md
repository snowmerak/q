## q란

q는 터미널을 위한 워크스페이스 중심 코딩 에이전트입니다. 저장소나 프로젝트 디렉터리에서 실행하면 대화, 파일 도구, 셸 명령, 모델 공급자, 계획, 서브에이전트, 검토, 영구 기록을 하나의 Go 바이너리로 제공합니다.

워크스페이스는 q 파일 도구의 작업 경계입니다. 셸 명령도 그 위치에서 시작하지만 **운영체제 샌드박스는 아닙니다**. 로컬 개발 셸과 같은 주의로 명령과 승인을 검토하세요.

## 워크플로 선택

범위가 명확하고 q가 바로 조사하거나 수정하기를 원한다면 일반 채팅을 사용하세요.

요구사항 명확화, 명시적인 제안, 실행 전 승인, 재개 가능한 체크포인트가 필요하면 `/plan`을 사용하세요. q는 Griller, Scout, Planner, 실행, Planner 검토 단계를 거칩니다.

대화형 승인 없이 같은 계획 워크플로를 실행하려면 `q sprint`를 사용합니다.

```powershell
q sprint implement the requested feature
```

하나의 제한된 작업을 전문가에게 맡길 때는 `/subagent`를, 신뢰할 수 있는 다른 프로세스가 HTTP를 통해 같은 세션과 에이전트 런타임을 사용해야 할 때는 `q remote`를 사용하세요.

## q가 보존하는 것

각 워크스페이스는 여러 영구 세션을 가질 수 있습니다. 보이는 대화 기록, 압축된 모델 컨텍스트, 작업 생명주기, 계획 체크포인트, 검색 가능한 워크스페이스 기록은 서로 분리해 저장됩니다. 덕분에 긴 작업에서도 전체 과거를 매 턴 전송하지 않고 상태를 살펴볼 수 있습니다.

q는 Agent Skills도 지원합니다. 스킬 메타데이터는 필요할 때 검색하고, 전체 `SKILL.md`는 에이전트가 적용 가능한 스킬을 불러온 뒤에만 모델 컨텍스트에 들어갑니다.

## 다음 단계

`go install` 또는 소스 체크아웃으로 q를 설치한 뒤, q가 이해해야 할 프로젝트에서 실행하세요.
