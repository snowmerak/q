## 작업 위임

워크스페이스 세션에서 `/mode delegation`을 입력한 뒤 원하는 결과를 설명하세요. 메인 에이전트는 manager에게 요구사항과 계획을 맡기고, senior developer에게 구현 지도를 맡길 수 있습니다. `q sprint <request...>`는 대화형 UI 없이 위임 작업 한 건을 실행합니다.

## 역할

manager는 PM 직책으로 요구사항, 우선순위와 수용 기준을 맡습니다. interviewer는 사용자 결정이 필요한 질문을 가려내고 researcher는 특정 문제를 조사합니다. senior developer는 `reviewer` 모델 역할로 junior developer에게 범위가 정해진 구현을 맡긴 뒤 실제 변경과 검증 결과를 직접 검토하고 필요하면 수정을 요청합니다. junior developer는 `coder` 모델 역할을 사용합니다.

각 역할은 필요한 워크스페이스 근거를 직접 읽을 수 있습니다. junior developer에게는 할당된 작업의 구현에 필요한 수정 및 명령 도구가 제공됩니다.
