# 티켓 실행 워크플로우 백로그

- [x] **이미지 입력** — Studio 채팅, 이슈, 티켓에 이미지를 첨부할 수 있다. 티켓과 연결된 이슈 본문의 첨부는 워커 입력으로 전달한다.
- [x] **검증 결과물** — 티켓 실행별 검증 보고서와 워커가 지정한 로그·스크린샷을 저장한다. 리뷰 화면에서 실행 ID와 제출 커밋을 확인할 수 있다.
- [x] **인박스** — 프로젝트별 시작 승인, 워커 질문, 리뷰와 실행 오류를 모아 보여준다. 질문에 바로 응답하거나 해당 티켓과 실행 기록을 열 수 있다. Studio가 열려 있으면 새 요청을 알린다.
- [ ] **간헐적인 컨텍스트 압축 중단 조사** — 압축이 40초를 넘긴 뒤 끊기는 경우를 재현한다. 수동·자동 압축을 구분하고, 중단을 발생시킨 경계와 압축 전 상태에서 복구 가능한지 확인한다.
